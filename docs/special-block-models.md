# 特殊方块模型与状态支持

结构编辑器为具有独立形状、安装方向或状态表现的方块提供专用模型。模型数据由结构编辑器读取方块状态后选择，并进入统一的场景和 Chunk 几何管理流程。

## 模型资源

- `assets/data/blockflow-special-models.json`：特殊方块状态模型数据。
- `assets/textures/structure/blockflow-special-atlas.png`：特殊模型使用的纹理图集。
- `StructureEditor/js/structure-app.js`：方块状态解析、模型选择、安装方向和方块实体文字处理。
- `StructureEditor/js/blockflow-baker.js`：特殊模型数据准备及几何编译入口。
- `StructureEditor/workers/geometry-baker.js`：Chunk 几何合并、索引化和 LOD 数据生成。

## 支持类别

- 拉杆：八种安装方向，以及开关状态。
- 告示牌：落地、墙面、悬挂和墙面悬挂；不同木种、朝向、连接状态和正反面文字。
- 按钮：木质与石质按钮，六面安装及按下/释放状态。
- 火把：普通、灵魂、铜、红石及墙面红石火把。
- 中继器：四向、四档延迟及供电状态。
- 比较器：四向、比较/减法模式及输出状态。
- 绊线钩和绊线。
- 红石粉：根据四个方向的连接状态动态生成平面连接几何。

告示牌文字从方块实体 NBT 读取，包括正反面文本、颜色和发光状态。文字几何叠加在牌面上。

## 安装方向与支撑面

模型以单个方块的中心为局部原点，通常使用 `[-0.5, 0.5]` 的局部坐标范围。模型父组放置在方块中心 `(x+0.5, y+0.5, z+0.5)`。

- 落地告示牌和顶部安装拉杆的底部锚点贴合方块底面，对应下方支撑方块的顶面。
- 悬挂告示牌的顶部锚点贴合方块顶面，对应上方支撑方块的底面。
- 墙面告示牌、墙面火把和墙面按钮会根据实际安装面旋转，并将支撑面定位到方块边界。
- 缺少拉杆方向状态时采用顶部安装默认值。
- 火把使用 `torch_facing_direction` 的支撑面语义；该状态与通用 `facing_direction` 使用不同的枚举定义。

## 渲染流程

状态解析得到模型键后，模型网格和纹理映射被装配为 Three.js 几何。普通方块与特殊方块最终进入统一的 Chunk 网格管理、视锥剔除和资源释放流程。

模型状态覆盖会随 Minecraft Bedrock 版本变化而调整。遇到未收录的状态时，编辑器可能使用通用几何或默认外观；实际效果应使用目标版本的结构文件进行检查。
