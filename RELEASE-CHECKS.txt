BlockFlow v2.11.4 — MCStructure-only / extracted Dislink special-block meshes

Model assets:
- 513 state-specific model entries extracted from the project's author-provided Dislink bake output and converted to BlockFlow.SpecialVoxelModels.
- Required model texture regions are repacked into a new 256x256 BlockFlow special atlas; UVs are remapped.
- Runtime does not load Dislink WASM, Emscripten runtime, bake.bin, bake_meta.json or Dislink workers.
- BlockFlow owns state selection, mounting rotation, sign NBT text overlays, model caching and Chunk integration.

Placement checks:
- Standing sign and top-mounted lever support plane is local y=-0.5.
- Hanging sign support plane is local y=+0.5 (ceiling block below face).
- Missing lever_direction defaults to up_north_south (top-mounted), not ceiling-mounted.
- Wall-hanging sign mesh is shifted 0.375 toward the supporting wall to close its recessed mount gap.
- Wall sign and wall torch mounting planes rotate onto the corresponding cell boundary x/z=+/-0.5.
- Buttons support six mounting faces; repeaters and comparators rest on y=-0.5.

Validation:
- Run `node --test tests/*.test.cjs`.
- Check all JavaScript files with `node --check`.
- Re-extract release ZIP and rerun tests.
- Automated coordinate and runtime geometry tests do not replace browser visual regression on real MCStructure samples.
