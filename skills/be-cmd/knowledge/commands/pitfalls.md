# 常见陷阱

按“症状 → 原因 → 处理”列。规范定义在 `chain-rules.md`，这里只收录会静默出错的表现。
写命令或改结构前扫一眼，能省很多排查时间。

## 结构文件

**导入 BlockFlow 后一条长链被拆成几十条。**
把 `fill`/`clone`/`structure` 的相对坐标当成了断链标记。只有
`/setblock ~~~-1 chain_command_block` 与 `/setblock ~~~ chain_command_block`
才是标记。

**链方向整体转了 90° / 相对坐标全错。**
相对坐标被旋转了两次。归一化只在导入时做一次，且按链的整体方向旋转。

**导出后命令方块全部变成空气。**
`block_indices` 的线性索引算错。公式是 `x*(Y*Z) + y*Z + z`，不是 `(y*Z+z)*X`。

**命令方块存在但没有命令。**
`block_position_data` 的键用的是世界坐标或 (x,z,y) 顺序。键必须是线性索引的
十进制字符串。

**结构在游戏里落点偏移。**
`structure_world_origin` 变了。布局坐标与 origin 是两回事，编辑时保留原 origin。

**v1 文件被 v2 程序读坏。**
v1 的 `structure` 是 compound，不是压缩 byte_array；`block_indices` 是
`List<List<Int>>`。按 `format_version` 分支处理。

**文件被截断 / zlib 报错。**
导出时没等压缩流结束，或者写文件时用了文本模式。二进制写要用 `wb`。

## 命令方块

**循环链只执行了第一条。**
后续方块是条件执行，而第一条失败了。要么把条件位设 0，要么保证第一条成功。

**链不执行。**
- 循环方块没“保持开启”，需要红石；
- 朝向没有指向前一个方块（连锁方块必须被指向）；
- 链中间夹了空气。

**同一 tick 执行了两次。**
两条链条件重叠。用互斥的分数区间，或在第一条命令里立刻改状态。

**链里有第二个循环方块。**
一条链只允许一个。多出来的必须拆成新链。

**断链标记朝向被“修正”后链断了。**
第二个标记的 `facing_direction=1` 是规范的一部分，不要改。

## 命令文本

**`execute` 不生效。**
1.19.80 之后必须 `… run <命令>`；旧语法 `/execute @a ~ ~ ~` 已被移除（网易旧版除外）。

**`at @` 让断链头识别失败。**
`/execute … at @s run …` 是普通命令，不是断链头。这是规范，不是 bug。

**tellraw/titleraw 没输出。**
JSON 不合法（尾逗号、中文引号、未转义双引号）。用 `mcbe.js check --only chain` 能定位。

**`§` 颜色不生效。**
`§` 必须是 U+00A7。从网页复制的 `§` 有时是全角或不可见字符。

**选择器匹配不到人。**
- `scores={x=1..5}` 中的 `..` 是全角句号；
- `type=` 要用命名空间 `minecraft:zombie`（多数时候可省略）；
- 基岩版没有 `nbt=`。

**分数溢出。**
计分板是 32 位有符号整数，`2147483647 + 1` 会变成负数。做大数运算前先缩小。

**目标名非法。**
计分板 objective 只能字母/数字/下划线，≤16 字符；中文会失败。

**命令太长被截断。**
`tellraw` 的 JSON 尤其容易超长。拆成多条 `tellraw`，或把静态文本放进语言文件。

## 布局与导出

**单条链超过 64 格。**
不能截断。要么把它拆成两条逻辑链（用断链头连接），要么减少命令数。

**导出分片后某片不能用。**
分片必须按整条链切；切在链中间会丢命令方块。

**Y 层堆叠后 z 越界。**
第二行起容量是 31/30/29，超过就会绕回；让 `layout` 计算，不要手写坐标。

**导出文件比原文件大很多。**
v1（旧版/网易）不压缩，体积约为 v2 的 20 倍，正常。

## 工具使用

**`mcbe.js` 报 `block outside size`。**
显式传了 `size` 但方块坐标超出。要么传 `None` 让它按包围盒归一化，要么先平移。

**`verify` 报 MISSING/EXTRA。**
导出→读回后命令文本变了，通常是二次旋转相对坐标。检查归一化是否只做了一次。

**中文乱码。**
Windows 控制台默认 GBK。`mcbe.js` 已把 stdout 设成 UTF-8；自己写脚本时加
`sys.stdout.reconfigure(encoding="utf-8")`。
